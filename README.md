# 🕹️ Play Subway Surfers with Real-Life Movements  

Ever thought about **playing Subway Surfers without touching the keyboard**?  
This project turns **your body movements into game controls** using **Python, OpenCV, and MediaPipe**.  

## ✨ Features
- 👆 **Jump in real life** → Character jumps  
- 👈 **Lean left** → Move left  
- 👉 **Lean right** → Move right  
- 👇 **Lean forward** → Slide down  
- Real-time **pose detection** with MediaPipe  
- **Keyboard events** simulated with pynput  
- Live feedback with **on-screen markers & FPS counter**

## 🛠️ Tech Stack
- **Python 3**
- [OpenCV](https://opencv.org/) – Video capture & visualization  
- [MediaPipe](https://developers.google.com/mediapipe) – Pose detection  
- [pynput](https://pynput.readthedocs.io/) – Simulating keyboard input  
- **NumPy** – Array & math operations  



## 📌 Notes

- Best played with good lighting and a webcam at chest level.

- Marker lines help guide you (can be turned off for better FPS).

- Tested on Windows. Should work on other platforms with small tweaks.
